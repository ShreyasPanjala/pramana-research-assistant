Attention is a mechanism in neural networks that allows a model to focus on different parts of the input when producing each part of the output. Instead of treating all input equally, attention computes a weighted relevance score between elements, so the model can "attend" more strongly to the most relevant parts. In self-attention, this happens within a single sequence: each word attends to every other word to build context-aware representations. Multi-head attention runs several attention computations in parallel, each potentially capturing different types of relationships, then combines their results.
